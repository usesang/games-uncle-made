# 주안이와 시안이: 공룡알 대소동

브라우저에서 바로 즐길 수 있는 2D 공룡 아케이드 게임입니다. `index.html`을 열면 실행됩니다. 인터넷 연결이나 설치는 필요하지 않습니다.

## 조작

- `←` `→` 또는 `A` `D`: 이동
- `Space` `↑` 또는 `W`: 점프
- `C`: 주안이 / 시안이 교대
- `V`: 아빠가 달려와 주인공의 양쪽 중 가장 가까운 공룡에게 꿀밤을 때리고 걸어서 퇴장
- `P`: 일시정지
- 휴대폰·태블릿: 화면 아래의 터치 버튼

모바일에서는 게임이 가로 화면 비율로 자동 배치됩니다. 세로로 들고 있어도 게임 화면을 가로 방향으로 돌려 보여주며, `게임 시작`을 누르면 지원되는 브라우저에서 전체화면·가로 방향 고정을 시도합니다. 브라우저가 이를 허용하지 않아도 화면 자체는 가로 게임으로 표시됩니다. 게임 영역에서는 글자 선택과 확대·스크롤 제스처가 비활성화됩니다. 정보는 상단에, 반투명 터치 버튼은 게임 화면 하단에 표시됩니다.

브라우저 주소창 없이 앱처럼 실행하려면 화면 상단의 **앱 설치** 버튼을 누르세요. Android에서 브라우저가 지원하면 설치 확인창이 열립니다. iPhone/iPad는 Safari의 공유 메뉴에서 **홈 화면에 추가**를 직접 선택해야 합니다. 홈 화면에 생긴 아이콘으로 실행하면 브라우저 탭 대신 독립된 게임 화면으로 열립니다. 기기와 브라우저에 따라 상태 표시줄 같은 시스템 UI는 남을 수 있습니다. 게임 중 이동과 점프를 동시에 터치해도 확대 제스처가 시작되지 않도록 차단합니다.

주안이는 바위에 달려들어 부술 수 있고, 시안이는 공중에서 한 번 더 점프할 수 있습니다. 각 스테이지의 공룡알을 전부 모아 오른쪽 끝 둥지에 도착하면 다음 지역으로 이동합니다. 알은 높은 발판에도 있으니 시안이의 이중 점프를 활용하세요. 적 공룡의 머리 위로 내려오면 튕겨 오르며 점수를 얻습니다.

## 다섯 스테이지

1. 햇살 초원: 기본 이동과 랩터
2. 버섯 숲: 높은 발판과 날아다니는 익룡
3. 화산 계곡: 가시와 트리케라톱스
4. 수정 동굴: 더 촘촘한 적과 장애물
5. 달빛 둥지: 모든 공룡과 티라노 추격

하트 5개로 시작합니다. 스테이지를 통과하면 점수가 이어지고 하트는 다시 5개로 회복됩니다. 실패하면 해당 스테이지의 시작 점수로 재도전할 수 있습니다.

주안이·시안이의 원본 캐릭터 시안은 `assets/concepts/juan-sian-character-sheet-v1.png`, 아빠의 사진 기반 시안은 `assets/concepts/dad-character-sheet-v1.png`에 있습니다. 첫 화면은 원본 시안을 바탕으로 한 `assets/concepts/title-screen-v2.png`를 사용합니다. 게임 속 주안이와 시안이는 투명 배경 기본 이미지와 달리기·점프 자세 시트를 사용합니다. 아빠는 주인공과 같은 속도로 등장해 주인공의 좌우에서 가장 가까운 공룡(활동 중인 티라노 포함)을 5초간 기절시키고, 점프를 멈춘 뒤 걸어서 퇴장합니다. 익룡, 랩터, 트리케라톱스, 티라노도 두 가지 동작 프레임으로 움직입니다. 아기 공룡은 주인공을 따라 이동하고 함께 점프합니다. 알·화석 동전·바위·가시·둥지와 자연스럽게 끝나는 발판도 같은 그림체의 소품을 사용합니다. 각 스테이지에는 별도의 배경 그림이 있으며, 바닥은 월드 좌표에 고정된 타일로 끊김 없이 이어집니다.
